# Sandbox

Small todo app. Node 22, no dependencies. Logic in `src/todo.js`, HTTP in `src/server.js`, page in `public/index.html`.

- Tests: `node --test`. Run them until they pass.
- App: `node src/server.js` then open http://127.0.0.1:8787
- Keep the change small. Add or update a test for the behavior you change.
- Do not push, open a pull request, or change Linear. The controller does that.
- Do not add dependencies.
